# Code of Conduct

## Our standard

We want participation in Talmudic AI Memory to be technically rigorous, respectful, and useful.

Examples of expected behavior include:

- discussing ideas and implementations on their merits;
- challenging claims with evidence;
- being clear about uncertainty and limitations;
- giving actionable technical criticism;
- respecting privacy and responsible-disclosure boundaries.

Unacceptable behavior includes harassment, threats, discriminatory abuse, deliberate disclosure of private information, or publishing security vulnerabilities irresponsibly.

## Enforcement

Repository maintainers may edit or remove comments, issues, pull requests, or contributions that violate these expectations and may restrict participation when necessary.

For sensitive conduct issues, contact the maintainers privately through GitHub rather than posting personal details publicly.
